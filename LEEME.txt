PROJECTORSCALER PORTABLE 2.0 — Windows 10/11 (x64)
================================================

REQUISITOS
- Windows 10 version 1703 o posterior, o Windows 11; arquitectura x64.
- Dos salidas de vídeo detectadas por Windows, preferiblemente monitor principal + proyector.
- No necesita .NET, instalador ni bibliotecas externas.

PRIMER USO
1. Descomprime el ZIP en una carpeta con permisos de escritura.
2. Conecta el proyector. Puedes tener Win + P > Extender o Duplicar.
3. Ejecuta ProjectorScalerPortable.exe.
4. Pulsa IDENTIFICAR PANTALLAS para mostrar el número de cada monitor.
   En Duplicar no se pueden mostrar números distintos porque ambas salidas
   muestran la misma imagen. En ese caso, al iniciar proyección se solicita
   autorización para pasar TEMPORALMENTE a Extender.
5. Elige origen (lo que se captura) y destino (proyector). Por seguridad, la
   aplicación impide iniciar sobre la pantalla que contiene la interfaz.
6. Pulsa INICIAR PROYECCIÓN y ajusta tamaño, posición y relación de aspecto.
7. Pulsa DETENER PROYECCIÓN. Si empezó desde Duplicar, la aplicación intentará
   restaurar Duplicar siempre que esté marcada la casilla correspondiente.

TECLA DE SEGURIDAD
Ctrl + Alt + P: detener la proyección y restaurar la configuración si procede.

AJUSTES
- Tamaño en %, posición horizontal/vertical 0-100.
- Formatos: 16:9, 16:10, 4:3, 21:9, 1:1, personalizado.
- Ajustar (sin deformar), Rellenar (recorta), Estirar (puede deformar).
- Perfiles, pantalla negra, cursor opcional y botón de actualizar monitores.
- La configuración se guarda en ProjectorScaler.ini al lado del ejecutable.

IMPORTANTE SOBRE EL MODO DUPLICAR
Windows comparte la misma imagen entre ambas salidas cuando están en Duplicar.
La reducción independiente del proyector solo se puede hacer con salidas
extendidas. ProjectorScaler puede pedir permiso y cambiar a Extender durante
la presentación; opcionalmente restaura Duplicar al detenerse. Esto cambia
la topología de Windows y puede reorganizar temporalmente las ventanas.

ESTADO / LIMITACIONES
- Compilado para Windows x64 y analizadas importaciones Win32; NO probado
  en una sesión real de Windows 10, Windows 11 o con un proyector HDMI.
- Versión GDI de hasta 20 fps; no idónea para cine fluido, DRM ni juego.
- No modifica el audio, no apaga ópticamente la luz del proyector.
- El EXE no tiene firma de código; SmartScreen podría mostrar una advertencia.
- Es necesario poder escribir en la carpeta para guardar perfiles.
- Versiones de Windows 10 anteriores a 1703 no están soportadas.
- La identificación/cambio de topología con >2 monitores no está validada.

VERSIÓN
ProjectorScaler Portable 2.0 — compilado en el entorno de desarrollo Linux
por clang/lld para Windows x86_64; implementación nativa Win32/GDI.
