PROJECTORSCALER PORTABLE 2.1 — Windows 10/11 (x64)
================================================

REQUISITOS
- Windows 10 version 1703 o posterior, o Windows 11; arquitectura x64.
- Dos salidas de vídeo detectadas por Windows, preferiblemente monitor principal + proyector.
- No necesita .NET, instalador ni bibliotecas externas.

PRIMER USO
1. Descomprime el ZIP en una carpeta con permisos de escritura.
2. Conecta el proyector. Puedes tener Win + P > Extender o Duplicar.
3. Ejecuta ProjectorScalerPortable.exe.
4. Pulsa IDENTIFICAR PANTALLAS para mostrar el número de cada monitor.
   En Duplicar no se pueden mostrar números distintos porque ambas salidas
   muestran la misma imagen. En ese caso, al iniciar proyección se solicita
   autorización para pasar TEMPORALMENTE a Extender.
5. Elige origen (lo que se captura) y destino (proyector). Por seguridad, la
   aplicación impide iniciar sobre la pantalla que contiene la interfaz.
6. Pulsa INICIAR PROYECCIÓN y ajusta tamaño, posición y relación de aspecto.
7. Pulsa DETENER PROYECCIÓN. Si empezó desde Duplicar, la aplicación intentará
   restaurar Duplicar siempre que esté marcada la casilla correspondiente.

TECLA DE SEGURIDAD
Ctrl + Alt + P: detener la proyección y restaurar la configuración si procede.
Si otro programa ya usa Ctrl + Alt + P, la tecla pasa a Ctrl + Alt + Mayús + P;
la línea de estado dice siempre cuál está activa, o avisa si no hay ninguna.

CAMBIAR DE MODO
El botón "Pasar a DUPLICAR" / "Pasar a EXTENDER" cambia el modo de Windows sin
pasar por Win + P. Si había una proyección en marcha, se detiene. Un cambio
manual no se deshace solo al detener la proyección.

AJUSTAR EL ENCUADRE CON EL RATÓN
Con la proyección en marcha, pulsa "Ajustar con el ratón" y lleva el puntero a
la pantalla del proyector: aparece un marco ámbar con tiradores.
- Arrastra el centro para mover la imagen.
- Arrastra un borde para estirarla hacia ese lado; una esquina, en dos sentidos.
- Mantén Mayús al arrastrar una esquina para conservar la proporción.
El formato pasa a "Libre (con el ratón)" y se guarda, también en los perfiles.
Pulsa "Terminar ajuste" para quitar el marco. Elegir otro formato o un perfil
vuelve al ajuste por tamaño y posición.

AJUSTES
- Tamaño en %, posición horizontal/vertical 0-100.
- Formatos: 16:9, 16:10, 4:3, 21:9, 1:1, personalizado y libre (con el ratón).
- Ajustar (sin deformar), Rellenar (recorta), Estirar (puede deformar).
- Perfiles, pantalla negra, cursor opcional y botón de actualizar monitores.
- La configuración se guarda en ProjectorScaler.ini al lado del ejecutable.

IMPORTANTE SOBRE EL MODO DUPLICAR
Windows comparte la misma imagen entre ambas salidas cuando están en Duplicar.
La reducción independiente del proyector solo se puede hacer con salidas
extendidas. ProjectorScaler puede pedir permiso y cambiar a Extender durante
la presentación; opcionalmente restaura Duplicar al detenerse. Esto cambia
la topología de Windows y puede reorganizar temporalmente las ventanas.

ESTADO / LIMITACIONES
- El código 2.1 compila sin avisos (clang 22, -Wall -Wextra), pero NO está
  probado en una sesión real de Windows 10/11 ni con un proyector HDMI.
- Versión GDI de hasta 20 fps; no idónea para cine fluido, DRM ni juego.
- No modifica el audio, no apaga ópticamente la luz del proyector.
- El EXE no tiene firma de código; SmartScreen podría mostrar una advertencia.
- Es necesario poder escribir en la carpeta para guardar perfiles.
- Versiones de Windows 10 anteriores a 1703 no están soportadas.
- La identificación/cambio de topología con >2 monitores no está validada.

CAMBIOS EN 2.1
- Las pantallas elegidas en los desplegables se respetan al iniciar (en 2.0 se
  volvía a la selección anterior sin avisar).
- Cambiar de pantalla durante la proyección la reinicia sobre la nueva pareja
  sin volver a DUPLICAR.
- Los cambios de pantalla de Windows (que llegan en ráfagas) ya no cortan la
  proyección ni pierden la vuelta a DUPLICAR: se espera a que se asienten y se
  reajusta la salida; si ya no es válida, se detiene y se restaura DUPLICAR.
- Si el programa se cierra a la fuerza estando en EXTENDER temporal, al abrirlo
  de nuevo ofrece volver a DUPLICAR.
- La ventana se escala con el DPI de cada monitor y se reduce para caber en
  pantallas bajas (p. ej. 1366 x 768).
- La captura baja sola de 20 fps hasta 4 fps si el equipo no da abasto, para
  que el panel siga respondiendo.
- Avisa si no puede escribir ProjectorScaler.ini; Tab recorre los controles;
  puntero normal en todas las ventanas; un único botón "Aplicar y guardar".
- Botón para pasar entre EXTENDER y DUPLICAR; encuadre ajustable con el ratón
  sobre el proyector; icono propio en la barra de tareas y en el EXE.

VERSIÓN
ProjectorScaler Portable 2.1 — código fuente; se compila con clang/lld para
Windows x86_64 (ver COMPILACION.txt); implementación nativa Win32/GDI.
