PROJECTORSCALER PORTABLE 2.4 — Windows 10/11 (x64)
==================================================

WHAT IT DOES
Projects your screen, one window or one browser tab onto a projector at the
size and position you choose, without touching the projector's own settings.
One EXE, no installer, no .NET.

REQUIREMENTS
- Windows 10 version 1703 or later, or Windows 11; x64.
- Two video outputs detected by Windows, ideally the main screen plus a projector.
- No .NET, installer or external libraries.

LANGUAGE
The ES / EN buttons at the top right switch the whole app between Spanish and
English at once. The choice is saved; on first run the app follows Windows
(Spanish on a Spanish Windows, English otherwise).

TWO MODES: BASIC AND ADVANCED
The Básico / Avanzado (Basic / Advanced) buttons at the top switch between them.
The app always opens in Basic.

BASIC MODE
For the usual case: the projector shows the same as your screen, made smaller.
1. Connect the projector. Windows can be in Duplicate or Extend (Win + P).
2. The dark area is the projector, with your screen inside the amber frame.
   Drag the frame:
   - drag the middle to move the picture;
   - drag a corner to make it bigger or smaller (the proportions are kept).
   "Centre" puts the frame in the middle; "Fill screen" makes it as large as fits.
   The size is shown as a percentage and is saved.
3. Press PROJECT. If Windows is in Duplicate, the app switches to Extend while
   it projects, without asking, and always goes back to Duplicate when you press
   STOP.
4. While projecting, BLACK SCREEN turns the picture black with HDMI still on;
   press it again (Resume picture) to bring the picture back.

ADVANCED MODE
Everything else, in four sections.

01 WHAT TO PROJECT
Three tabs, each with a still of every source; click one to choose it. Clicking
a tab, even the open one, lists its sources again. If a projection is running,
it restarts on the new source.
When a tab has more sources than fit, section 01 grows to show them all and
sections 02, 03 and 04 fold down to their titles. They open again as soon as
you choose a source, or when you click one of the folded titles.
- Screens: a whole screen, with everything open on it.
- Windows: only that window (its content, without borders or title bar), even
  when other windows cover it on your screen.
  - If you resize the window, the projection follows.
  - If you minimise it, the projector keeps the last picture until you restore it.
  - If you close it, the last picture stays and the status line says so.
  - Some apps with hardware acceleration or DRM may show black.
- Tabs: one tab of Google Chrome or Microsoft Edge, showing only the page,
  without the browser's tab strip or address bar.
  - Choosing a tab makes it the tab on show in its browser window (a minimised
    browser window is restored, because a minimised window draws nothing).
  - Only the tab on show has a still; the others say "In background".
  - Safety: while projecting, the app checks about every half second (less
    often if the browser answers slowly) that the chosen tab is still the one
    on show, and on every frame that the browser's title
    has not changed. If it cannot confirm it (you switched tabs, the browser
    closed or stopped responding), the picture freezes and the status line
    says why. Go back to the tab in the browser and it resumes on its own.
The chosen window or tab is not saved: when the app is opened again, the source
is a screen.

02 PROJECTOR
- Target: the projector screen. For safety, the app refuses to project onto the
  screen that holds its own panel.
- IDENTIFY shows each screen's number. In Duplicate both outputs show the same
  picture, so the numbers cannot differ; the app then asks before switching
  TEMPORARILY to Extend when you start.
- Refresh reads the screens again.
- "Switch to DUPLICATE" / "Switch to EXTEND" changes the Windows mode without
  Win + P. A running projection stops. A manual change is not undone when the
  projection stops.

03 PICTURE AND GEOMETRY
- Size in %, horizontal and vertical position 0-100.
- Aspect ratios: 16:9, 16:10, 4:3, 21:9, 1:1, custom, and free (with the mouse).
- Fit (no distortion), Fill (crops), Stretch (may distort).
- Show pointer, and "Apply and save".
- ADJUST WITH THE MOUSE: while projecting, press it and move the pointer to the
  projector screen. An amber frame with handles appears.
  - Drag the middle to move the picture.
  - Drag an edge to stretch it that way; a corner, both ways.
  - Hold Shift while dragging a corner to keep the proportions.
  The aspect ratio becomes "Free (with the mouse)" and is saved, also in
  profiles. "Finish adjusting" removes the frame.

04 PROJECTION PROFILES
Cinema 16:9, Lecture 4:3, Small picture, and your own saved profiles.

Bottom: Start/Stop projection, Black screen (picture black, HDMI still on) and
"Restore DUPLICATE when finished".

EMERGENCY KEY
Ctrl + Alt + P stops the projection and restores the display settings where
needed. If another program already uses Ctrl + Alt + P, the key becomes
Ctrl + Alt + Shift + P; the panel always says which one is active, or warns if
there is none.

OPTIONS (THE GEAR AT THE TOP RIGHT)
- Start with Windows: opens ProjectorScaler when you sign in to Windows. It is
  off until you switch it on. It writes a value named ProjectorScaler under
  HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run that starts
  this EXE, so it is per user and needs no administrator rights. If you move
  the EXE, the tick goes off: switch it on again from the new copy. Switching
  it on here also clears a switch-off made in Task Manager > Startup apps.
- Check for updates at startup (on by default): a few seconds after opening
  (half a minute when started with Windows) the app asks GitHub for the latest
  release of cmmendel/ProjectorScaler. If there is a newer version, it asks
  whether to download and install it; nothing is downloaded unless you say
  yes. If you are projecting, it asks when the projection stops. Without
  Internet, or if GitHub does not answer, it says nothing and tries once more
  two minutes later.
- Check for updates now: the same check, with an answer either way.
Installing: the new EXE is downloaded next to the current one (as
<name>.exe.new), checked to be a 64-bit Windows program, and swapped in under
the same name; the old copy is kept as <name>.exe.old until the next start. The
app closes and opens again with the new version, keeping ProjectorScaler.ini.
If the folder cannot be written, the app offers the download page instead.

ABOUT DUPLICATE MODE
In Duplicate, Windows shows the same picture on both outputs, so the projector
can only be made smaller with extended outputs. ProjectorScaler switches to
Extend while it projects and can go back to Duplicate when it stops. This changes
the Windows display layout and may move windows around for a moment. If the app
is closed by force while in a temporary Extend, it offers to go back to Duplicate
the next time it opens.

SETTINGS FILE
Everything is saved in ProjectorScaler.ini next to the EXE, so the folder must
be writable. The app warns if it cannot write it. CheckUpdates=0 in [Settings]
switches off the check at startup.

STATUS / LIMITS
- Builds without warnings (clang 22, -Wall -Wextra). It has been checked on a
  real Windows 11 desktop with two screens, but NOT yet with an HDMI projector,
  and the projection itself (including the Duplicate/Extend switch and tab
  projection) has not been run in those checks.
- A whole screen (Basic mode, or the Screens tab) shown at exactly full size
  (1:1) is mirrored by the Windows magnifier, which the graphics card draws at
  the screen's refresh rate (measured: about 56 frames per second on a 60 Hz
  screen, in a small test window): meant for video. It is not yet checked on a
  projector. If the magnifier is not available, the app falls back to the slow
  capture below.
- A whole screen made SMALLER (the usual case) is copied by the graphics card
  (Windows desktop duplication) and shrunk by averaging every pixel it covers,
  so small text keeps its strokes. Made LARGER (a projector with more pixels
  than the screen) it is enlarged smoothly, instead of repeating some pixels
  twice and others once. Measured on a 60 Hz screen: about 60 frames per second
  shown, 51-58 new frames per second with moving content, at sizes from 20 % to
  80 % and enlarged 1.6 times. The magnifier is not used for this: it shrinks
  by dropping whole rows and columns, and enlarges by repeating pixels. If the
  graphics card path is not available (no DirectX 10 card, a remote desktop
  session), the app falls back to the slow capture below, which also averages.
  While Windows is locked or a UAC prompt is on screen the picture freezes and
  resumes about a second later.
- A single window or browser tab, Black screen, and adjusting the frame with
  the mouse use GDI capture, which averages when it shrinks but repeats pixels
  when it enlarges (a small window shown large looks blockier than a whole
  screen): about 13-20 frames per second (measured: 37 ms per 1920x1080 frame),
  down to 4 if the computer cannot keep up. Fine for slides and pages, not for
  video.
- The sound does not go through the app; Windows plays it as usual.
- Protected video (Netflix and similar, DRM) shows black on the projector.
- Does not touch audio and does not switch the projector's lamp off.
- The EXE is not code-signed; SmartScreen may warn on first run.
- Windows 10 before 1703 is not supported.
- Identifying and switching layouts with more than two screens is not validated.
- The graphics card path (2.4) was measured on a Windows 11 desktop with two
  screens: a 1-px line pattern averaged correctly at 80, 60, 50, 30 and 20 %,
  and interpolated when enlarged 1.6 times (a test build, since both screens
  here have the same resolution), about 60 frames per second, the frame dragged
  while projecting, and both the arrow and the text pointer drawn. Locking
  Windows, a UAC prompt, Win + P and a resolution change while projecting were
  not tried.
- Updates (2.3) were checked against a local stand-in for GitHub: prompt,
  download through a redirect, swap and restart, a corrupt download, a
  read-only folder and no network. Against the real GitHub, a copy reporting
  2.2 found the 2.3 release, downloaded it, swapped itself and reopened as 2.3,
  byte for byte the published EXE. The waits while projecting, and Black
  screen in Basic mode, have not been run on a live projection.
- On a 1366 x 768 laptop the Advanced panel is scaled down to fit, to about
  three quarters of its normal size.

CHANGES IN 2.4
- A smaller picture of a whole screen keeps its definition: the graphics card
  shrinks it by averaging pixels, at the screen's refresh rate, and enlarges it
  smoothly. The magnifier, which dropped rows and columns, is kept only for
  exactly full size.

CHANGES IN 2.3
- Options menu (gear): start with Windows, check for updates at startup, and
  check now.
- Updates from GitHub releases, installed only after you confirm.
- Basic mode has the Black screen button.
- The version is shown in the footer and in the title bar.

CHANGES IN 2.2
- Basic mode: mirror your screen and size it on the projector with the mouse.
- Advanced mode keeps every option; the source is chosen from stills in three
  tabs: Screens, Windows and Tabs.
- Browser tabs (Chrome, Edge) as a source, with the freeze-on-doubt guard.
- Spanish / English switch for the whole app.
- Footer credit with the build date, and a link to cmmendel.com.
- A whole screen is mirrored by the graphics card (Windows magnifier) for
  smooth video; the app always opens in Basic.

CHANGES IN 2.1
- One window can be projected instead of a whole screen.
- The screens chosen are kept when starting (2.0 went back to the previous
  choice without saying so).
- Changing screens while projecting restarts on the new pair without going back
  to Duplicate.
- Windows display changes (which arrive in bursts) no longer cut the projection
  or lose the return to Duplicate: the app waits for them to settle and adjusts
  the output; if it is no longer valid, it stops and restores Duplicate.
- The panel scales with each monitor's DPI and shrinks to fit short screens.
- Capture drops from 20 fps to 4 fps by itself if the computer cannot keep up.
- Warns if ProjectorScaler.ini cannot be written; Tab moves through the
  controls; one "Apply and save" button.
- Button to switch between Extend and Duplicate; frame adjustable with the mouse
  on the projector; own icon in the taskbar and the EXE.

VERSION
ProjectorScaler Portable 2.4 — native Win32/GDI, built with clang/lld for
